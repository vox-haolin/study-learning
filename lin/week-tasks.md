1.Ubuntu 下 C 项目 + Git 工作流
在 Ubuntu 终端里用 gcc + Makefile 写一个命令行小工具（比如串口数据解析器、或者用链表实现一个传感器数据缓存），全程 git init / add / commit / branch / merge 走一遍。你 Windows 上有 Git，但 Linux 终端里用 Git 才是嵌入式开发的真实日常。

2.Octave 跑一遍信号处理 demo
打开 Octave，生成一个正弦波 → 加噪 → FFT → 滤波 → 画图，整个流程跑通。未来信号与系统、数字信号处理、数字图像处理全会在这个路子，早熟悉早轻松。

3.Keil + STM32Cube 点亮一个外设
你已经学过项目驱动 MCU，现在拿 CubeMX 配一个 I2C/SPI 传感器（比如 OLED 屏或者温湿度），Keil 编译烧录，把数据用 VOFA 可视化出来。这是嵌入式岗简历上最基础的"我能干活"证明
